# Hopingo — le calcul en jouant

A Duolingo-style practice app for mental arithmetic and times tables, fractions, signed numbers, powers and square roots (HarmoS 5H–11H and gymnase, French), now growing towards the first two years of EPFL (BA1–BA4, see `docs/plan-universite.md` and the implementation spec `docs/universite/README.md`). It is fully static, with no server: everything runs in the browser and progress is saved in `localStorage`.

## Run it

ES modules don't load from `file://`, so serve the folder:

```sh
npm run serve        # python -m http.server 8080, then open http://localhost:8080
npm test             # math core, symbolic core, judges, content generators, learner engine
npm run samples      # writes docs/samples-<unit>.md for content review
```

There are no dependencies and no build step.

## Deploy on GitHub Pages

Push the folder to a repository, then go to **Settings → Pages → Deploy from a branch** and pick `main` / root. `.nojekyll` makes Pages serve the files as they are.

## How it works

| Piece | File | What it does |
|---|---|---|
| Exact math | `js/math/rational.js`, `expr.js` | Exact rationals. Parses keypad text, where `/` is the fraction bar, `^` an exponent and `√` a root. √2 × √8 and (√7)² are evaluated exactly. |
| Solver | `js/math/solver.js` | Canonical step-by-step solutions (signs, powers, roots included), used for guided blanks, hints and worked examples. |
| Mistakes | `js/math/malrules.js`, `diagnose.js` | Known errors (« pièges ») as rules. A wrong line is replayed under each rule, and under misreadings of its structure (priorities, brackets, −3² vs (−3)², √(a+b) = √a + √b…), to name the mistake. |
| Judge | `js/math/judge.js` | A line is valid if it keeps the exact value of the previous one, so any method is accepted. |
| Skills | `js/content/skills.js` | The skill graph: 378 skills in 30 units, prerequisites, intro cards, year (HarmoS 5–11, 12 gymnase, 12.5 CMS, 13–16 BA1–BA4). The global order is topological: a prerequisite always comes first. University units register in `js/content/uni/index.js`. |
| Questions | `js/content/items.js` and one file per unit: `calcul.js`, `fractions.js`, `relatifs.js`, `puissances.js`, `racines.js`, `arithmetique.js`, `proportion.js`, `algebre.js`, `equations.js`, `fonctions.js`, `seconddegre.js`, `melanges.js` (merged in `generators.js`) | One generator per skill, 5 levels each. Records which traps each question can catch. |
| Algebra | `js/math/algebra.js`, `checkers.js` | Expressions with letters: parser (3x, 2(x+1), x^2), exact polynomials and rational fractions, equivalence (numeric probing when a root appears), and form checks: « développé réduit », « factorisé (complètement) ». The checker says what is left to do and names the trap. |
| Equations | `js/math/equations.js` | Solution sets (degree ≤ 2, forbidden values removed), judging an equation line by line (same solutions = valid line), the next move for hints, and the classic wrong moves to name the mistake. |
| Symbolic core | `js/cas/` | For the university units: parser (a superset of `expr.js`: letters, functions, d(f), primes, relations, intervals ]a ; b[, finite sets, ∪ ∩ ∖, chains −2 < x ≤ 4, « et », « ou », « non », systems with « ; », log_a(x), sums sum(f, k, 1, n), angles in degrees, families with an integer k, integrals int(f, x) and int(f, x, a, b), brackets [F] from a to b, limits, bounds 0⁺ and 1⁻, the remainder ε(x) or o(xⁿ)), printers (keypad text, readable text, MathML), sparse polynomials and rational functions over ℚ, exact normal form, numeric sampling, equivalence (exact first, else 12 sampled points), symbolic derivatives. `sets.js`: solution sets as unions of intervals (exact bounds for rational functions, else a compiled numeric scan), domains of definition, substitutions; `logic.js`: formulas built from tokens, negation table, equivalence; `polyx.js`: polynomials in x with parameters or complex coefficients (Horner, division, rational roots, factored forms); `series.js`: truncated series (développements limités, at a point or at ±∞) with the remainder tracked; `limit.js`: limits by series, else numerically (windows of values that shrink: a limit that does not exist, sequences with n whole); `complex.js`: exact complex numbers in ℚ(i) and float complexes, algebraic and polar forms; series Σ to ∞ evaluated by partial sums and extrapolation; min, max and n!; `integrate.js`: double-exponential quadrature (singular ends, half-lines); `closedform.js`: exact numbers in final form (π, e, √, ln, arctan). | Line judges | `js/judges/` | One judge per kind of line (`value`, `equiv`, `solset`, `logic`, `poly`, and for calculus `series`, `antideriv` — a primitive is checked by differentiating it, so F + 3 is right too —, `definite` and `limit`, and from step U4 `complex` — same value, exact in ℚ(i), sets of complex roots — and `delta` — the δ(ε), N(ε) or x(ε) of a proof by the definition, checked on a dense sample —), a registry, trap diagnosis by replay, and the `lines` engine: segments, decisions, sub-goals, « continue with my line ». | Mock exams | `js/content/uni/exams.js`, `js/engine/exam.js`, `js/ui/screens/exam.js` | A blueprint (duration, sections, marks with negative points) gives a mock exam drawn from the exam variants of its units, weighted by each skill's exam weight. A visible timer, no hints, questions to skip and flag; then the estimated grade 1 + 5·score/max, the verdict « Prêt / Presque / Pas encore », the prediction from the mastery compared with the score, the skills to rework and the corrections. Reached from the unit's branch on the map (« Examen blanc »). |
| Learner | `js/engine/learner.js` | Mastery estimate per skill (Bayesian knowledge tracing), difficulty ladder, repair of prerequisites, spaced review, traps, hints, validation alone (`needsSolo`), and the branching path (`nextFocus`). |
| Facts | `js/engine/facts.js` | Memory of single number facts (7 × 8, 13²): a Leitner box per fact. A fact is automatic once answered right and fast twice. |
| Lessons | `js/engine/session.js` | Picks each question as you go: path, reviews, traps, mistakes again at the end. |
| Placement | `js/engine/placement.js` | Quick binary-search skim from the student's year and track. From BA1 on, and with « Je connais déjà ce module » on the map, the search runs unit by unit. |
| Rewards | `js/engine/rewards.js` | XP, daily goal, streak with freezes, badges. |

**The path branches.** After the first mental arithmetic, several units are open at once. « Continuer » keeps up to 3 active branches and moves from one to the next at each lesson, so topics mix; a new branch starts with the skill that opens the most others, at the student's current level. A branch can be pinned on the map, any open skill can be started, and a closed skill shows the prerequisite it waits for. Prerequisites are only the skills the exercises really use.

**Adapting to the student:**
- **Difficulty:** each skill has a level from 1 to 5. Two fast correct answers move it up a level. Two mistakes, or three slow answers, move it down. "Slow" is measured against the student's own pace on that skill.
- **Regression:** failing again at level 1 sends practice to the weakest prerequisite, marked 🧱/🩹 on the map, until that skill is solid.
- **Spaced review:** mastered skills come back for review, and the interval ×2.5 after each success. Skills skipped by the placement skim are due right away, so the reviews confirm them.
- **Traps:** a mistake becomes a trap after it happens twice. It is beaten by answering the questions that bait it correctly on 3 different days.

**Fast series** (times tables, sums to 20, squares, mental ± ):
- 15 short questions, no "Vérifier": the answer is judged as soon as it has enough digits, and a right answer moves straight on.
- The response time is measured but never shown. A fact counts as automatic when it is right in about 3 seconds.
- Each fact has its own spaced memory. A series mixes about 70 % known facts with a few new or fragile ones, and a missed fact comes back two questions later.
- A mistake shows the full fact, the trap with the question's own numbers, and a strategy (9 × 6 = 60 − 6).

**Step-by-step modes** (multi-step skills and the operation skills of every unit):
- **Guided:** fill in the new numbers of each canonical step. A new negative number is one blank, sign included.
- **Tap then solve:** tap the operation to do next (an operator, an exponent or a root sign). Tapping the wrong one is caught as a priority mistake.
- **Free lines:** rewrite the expression line by line, with "Recopier la ligne" and hints.

Square roots stay exact: questions only use roots that come out whole or rational (√49, √(9/16), √2 × √8). Simplifying √50 = 5√2 is not covered.

To add a skill:
1. Add it to its unit's list in `js/content/skills.js` (a university skill: `js/content/uni/<unit>.skills.js`), with its year, prerequisites and intro.
2. Add a generator to `GEN` in the unit's file in `js/content/` (university: `js/content/uni/<unit>.js`; a new unit is listed in `js/content/uni/index.js` and `uni/generators.js`).
3. Add any new mistakes to `RULES` in `js/math/malrules.js` (university: `js/cas/rules/<module>.js`, with a `transform` that replays the mistake on the previous line), with a general explanation for when no numbers are available.
4. Run `npm test`. It generates 200 items per skill and checks they are consistent, and checks every trap points to a real skill. For university skills it also replays every reference solution through its own judge, and checks each trap names its own example.
