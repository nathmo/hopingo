# Exemples de questions — Analyse complexe

Généré par `npm run samples` (graine fixe). Trois exemples par niveau.
`[guided]` = étapes à trous, `[tap]` = on touche l'opération à faire, `[free]` = lignes libres.
Lignes : « = … » est une ligne du corrigé, avec sa règle après ←. Les cases □ sont à remplir (la réponse est entre parenthèses). « ? » est une décision à choisir, « — » ouvre une nouvelle partie jugée par un autre juge.
Les « pièges » sont les erreurs connues que la question peut détecter (voir docs/error-catalogue.md).

## Résidu en un pôle simple (`c-res-simple`, BA3)

_Res(p/q ; z₀) = p(z₀)/q′(z₀) quand q a un zéro simple en z₀._

### Niveau 1

```
z₀ = 2i est un pôle simple de f(z) = e^(3iz)/(z² + 4). Calcule Res(f ; 2i).
  [guided]  Res(f ; 2i)
    (Le dénominateur est q(z) = z² + 4, q′(z) = 2z et q′(2i) = 4i. Le numérateur vaut p(2i) = e^−6.)
    = e^(−6)/(□)   (trous : e^(−6)/(4i))   ← p(z₀) = e^(−6), q′(z₀) = 4i
    = □   (trous : −ie^(−6)/4)   ← Simplifier
  aides : Pôle simple de p/q : Res(f ; z₀) = p(z₀)/q′(z₀). | q′(z) = 2z, donc q′(2i) = 4i. | Res = e^−6/(4i) = −ie^−6/4
  pièges : c_essential_factor

z₀ = −π est un pôle simple de f(z) = z/(sin(z)). Calcule Res(f ; −π).
  [guided]  Res(f ; −π)
    (Le dénominateur est q(z) = sin(z), q′(z) = cos(z) et q′(−π) = −1. Le numérateur vaut p(−π) = −π.)
    = π   ← Simplifier
  aides : Pôle simple de p/q : Res(f ; z₀) = p(z₀)/q′(z₀). | q′(z) = cos(z), donc q′(−π) = −1. | Res = (−π)/(−1) = π

z₀ = −π est un pôle simple de f(z) = 1/(sin(z)). Calcule Res(f ; −π).
  [guided]  Res(f ; −π)
    (Le dénominateur est q(z) = sin(z), q′(z) = cos(z) et q′(−π) = −1. Le numérateur vaut p(−π) = 1.)
    = 1/(□)   (trous : 1/(−1))   ← p(z₀) = 1, q′(z₀) = −1
    = □   (trous : −1)   ← Simplifier
  aides : Pôle simple de p/q : Res(f ; z₀) = p(z₀)/q′(z₀). | q′(z) = cos(z), donc q′(−π) = −1. | Res = 1/(−1) = −1

```

### Niveau 2

```
z₀ = π/2 est un pôle simple de f(z) = z/(cos(z)). Calcule Res(f ; π/2).
  [guided]  d/dz q(z)
    ? Quelle formule pour ce pôle simple ? ✔ Res = p(z₀)/q′(z₀) / ✔ Res = lim (z − z₀)·f(z) / ✔ Développer f en série de Laurent / · Res = p(z₀)/q(z₀)
    = □   (trous : −sin(z))   ← Dériver q
  — q′(z) = −sin(z). En z₀ :  [juge cval]  départ : d/dz q(π/2)
    = □   (trous : −sin(π/2))   ← Remplacer z par z₀
    = □   (trous : −1)   ← Calculer
  — Le résidu :  [juge cval]  départ : Res(f ; π/2)
    = □   (trous : −π/2)   ← Simplifier
  aides : Pôle simple de p/q : Res(f ; z₀) = p(z₀)/q′(z₀). | q′(z) = −sin(z), donc q′(π/2) = −1. | Res = (π/2)/(−1) = −π/2

z₀ = 2i est un pôle simple de f(z) = z/((z − 2i)(z + 1)). Calcule Res(f ; 2i).
  [guided]  d/dz q(z)
    ? Quelle formule pour ce pôle simple ? ✔ Res = p(z₀)/q′(z₀) / ✔ Res = lim (z − z₀)·f(z) / ✔ Développer f en série de Laurent / · Res = p(z₀)/q(z₀)
    = □   (trous : 2z + 1 − 2i)   ← Dériver q
  — q′(z) = 2z + 1 − 2i. En z₀ :  [juge cval]  départ : d/dz q(2i)
    = □   (trous : 2(2i) − (−1 + 2i))   ← Remplacer z par z₀
    = □   (trous : 1 + 2i)   ← Calculer
  — Le résidu :  [juge cval]  départ : Res(f ; 2i)
```

## Montrer qu'une intégrale sur un arc tend vers 0 (`c-arc-estimate`, BA3)
